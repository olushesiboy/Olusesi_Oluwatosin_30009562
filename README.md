## Project Overview
This project focuses on the design, implementation and evaluation of database technologies using RoyalTee Chow Logistics as a case study.

The project demonstrates relational database design, SQL query processing, transaction management, NoSQL database implementation, and distributed and cloud database concepts.

## Portfolio Structure

### Portfolio 1 – Database Design and Implementation
Design and implementation of the relational database using MySQL, including tables, primary keys, foreign keys and relationships.

### Portfolio 2 – Query Processing and Optimisation
SQL queries demonstrating data retrieval, filtering, sorting, aggregate functions, grouping, joins and query execution plans.

### Portfolio 3 – Transactions and Concurrency
Practical demonstrations of database transactions, COMMIT, ROLLBACK, isolation levels and row locking.

### Portfolio 4 – NoSQL and Advanced Data Models
Implementation of document-based data storage using MongoDB Atlas, with illustrative key-value, column-family and graph-oriented representations.

### Portfolio 5 – Distributed and Cloud Database
Exploration of MySQL binary logging and cloud database deployment using MongoDB Atlas.
